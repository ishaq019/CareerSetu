# CareerSetu Product Specification

## Primary user journey

**Upload/paste resume -> add JD -> analyze -> understand fit -> close gaps -> prepare -> apply.**

## Guest report

The report must answer four practical questions:

1. How well does my current resume match this role?
2. What evidence already supports the role?
3. What important skills are missing or under-demonstrated?
4. Should I apply now or improve first?

## Skill-gap roadmap

Each gap should include:

- skill
- target level: basic/intermediate/advanced
- priority
- learning sequence
- practice/project evidence
- resume evidence requirement
- re-analysis checkpoint

The platform must never tell users to claim skills they do not genuinely possess.

## Authenticated features

- adaptive interview preparation
- resume optimization
- LaTeX resume PDF
- professional cover letter PDF
- grounded company/JD chat
- persistent roadmap/progress
- application history

## RAG knowledge

The knowledge base should contain trusted interview preparation documents such as roadmaps, coding questions, interview questions and answer guides. Every chunk should retain source metadata.
